# Chartwells Digital Logs & Forms

A web app for dining services teams to complete, store, and review shared logs and forms across multiple dining locations.

## Purpose

Give each location a convenient way to maintain its records and give managers a central view of required log completion, reducing the need to visit every location just to check whether forms have been filled out.

## Planned capabilities

- Digital forms and logs organized by dining location.
- Completion tracking for required logs across locations.
- Searchable historical records for review and follow-up.
- Manager dashboards showing completed, pending, and overdue logs.
- Location-based access for staff and managers.

## Status

Project setup and planning. The application has not been implemented yet.

Real operational records, credentials, and personal information must stay out of this public repository.
